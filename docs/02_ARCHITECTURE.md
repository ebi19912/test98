# 🏛️ معماری کلان و ساختار مهندسی پلتفرم تست ۹۸ (test98.ir)

این سند تشریح‌کننده اصول مهندسی نرم‌افزار، لایه‌بندی سیستم، فناوری‌های به‌کاررفته، چرخه حیات درخواست‌ها و همزمانی در پلتفرم **تست ۹۸** است.

---

## ۱. نمای کلی سیستم و فلسفه طراحی

پلتفرم تست ۹۸ با هدف ایجاد یک **موتور آزمون‌ساز تطبیقی، خبرخوان استخدامی و بانک جامع نمونه سوالات سال‌های گذشته** طراحی شده است. 

### اصول بنیادین معماری:
1. **سبک، مستقل و بدون سربار (Zero-Overhead Stack):**
   - استفاده از **FastAPI** برای سرعت بالای Asynchronous I/O.
   - پایگاه داده تک‌فایلی بهینه‌شده **SQLite WAL** (بدون نیاز به نگهداری سرویس‌های سنگین مانند Postgres/MySQL در فاز اولیه).
   - فرانت‌اند مدرن **HTML-over-the-wire** با ترکیب **Tailwind CSS + HTMX + Alpine.js** بدون نیاز به فرانت‌اندهای سنگین React/Vue و بیلد‌های طولانی.
2. **پایداری ۲۴/۷ و تاب‌آوری (High Reliability):**
   - استخراج نوبتی و پیمایش پس‌زمینه خودکار (Background Round-Robin).
   - احراز هویت دوطرفه با پیام‌رسان بله با دو حالت پولینگ محلی و وب‌هوک سرور.
3. **تجربه کاربری محلی‌سازی‌شده (Localization & RTL First):**
   - تقویم شمسی رسمی (Jalali Date Filter) روی تمام جداول و گزارش‌ها.
   - تایپوگرافی فارسی اصیل با فونت استاندارد Vazirmatn.
   - پشتیبانی از اعداد فارسی و تبدیل خودکار به انگلیسی در سرور.

## ۴. چرخه حیات سرور (Lifespan Lifecycle)

در فایل `main.py` از ساختار جدید `asynccontextmanager` در FastAPI استفاده شده است:

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    # ۱. راه‌اندازی ساختار دیتابیس (جداول ۱۲ گانه در صورت نبود)
    await init_db()
    # ۲. تزریق داده‌های نمونه اولیه استاندارد در صورت خالی بودن دیتابیس
    await seed_initial_data()

    # ۳. اتصال یوزربات تلگرام (در صورت فعال بودن در .env)
    if telegram_client and settings.TELEGRAM_ENABLED:
        await telegram_client.start()

    # ۴. راه‌اندازی ورکر پس‌زمینه استخراج دوره‌ای (هر ۳۰ دقیقه)
    crawler_task = asyncio.create_task(periodic_crawler_worker(interval_seconds=1800))

    # ۵. راه‌اندازی ورکر پولینگ زنده بله (Bale Long Polling)
    bale_task = asyncio.create_task(bale_polling_worker())

    yield  # سرور آماده دریافت درخواست‌های کاربران است

    # خاموش‌سازی تمیز (Graceful Shutdown)
    crawler_task.cancel()
    bale_task.cancel()
    if telegram_client and telegram_client.is_connected():
        await telegram_client.disconnect()
```

## ۵. امنیت و محافظت از داده‌ها

1. **انتقال ایمن سوابق مهمان به کاربر رسمی (Frictionless Onboarding):**
   - کاربر بدون نیاز به ثبت‌نام می‌تواند در آزمون‌ها شرکت کند؛ یک شناسه تصادفی `guest_token` در کوکی او ذخیره می‌شود.
   - به محض ورود داوطلب از طریق بله، تمام کارنامه‌ها و پاسخ‌های ذخیره‌شده مهمان به اکانت جدید او منتقل (`UPDATE exam_attempts SET user_id = ...`) می‌گردد.
2. **پالایش ورودی‌ها و جلوگیری از تزریق SQL:**
   - تمام دستورات دیتابیس از طریق کوئری‌های پارامتریزه شده (`?`) توسط درایور `aiosqlite` اجرا می‌شوند.
3. **محافظت از فایل‌های حساس:**
   - توکن ربات بله، دیتابیس، لاگ‌ها و سشن‌های تلگرام به طور خودکار در `.gitignore` قرار دارند.
4. **کوکی‌های امنیتی:**
   - کوکی‌های هویتی دارای فلگ‌های `HttpOnly` و `SameSite=Lax` جهت جلوگیری از حملات XSS و CSRF هستند.
